# Portada del portfolio

Modo principal: **Persuade**. Éxito del visitante: entender qué puede contratar, comprobar trabajo real y abrir una consulta.

La zona de proyectos toma el enfoque **Experience**: las capturas y los casos llevan el protagonismo. Las tecnologías no ocupan el acceso principal. El objetivo secundario es permitir que un recruiter encuentre proyectos, CV y capacidades.

La identidad visual vigente es autoridad: NA, negro y violeta. Se modifica la jerarquía, el orden y el nivel de detalle. No se crea una nueva marca ni se inventan pruebas comerciales.
